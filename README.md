# ono-tebe-nado

Вёрстка страницы «Оно тебе надо» — аукциона вещей, в которые никто не верил. Страница рассчитана на ширину 1100 px.

Репозиторий проекта: https://github.com/Melchonok/ono-tebe-nado-ad

## Запуск

Откройте `index.html` в браузере. Установка зависимостей и сборка не требуются.


## Технологии

- HTML5 и CSS3;
- CSS Grid и Flexbox;
- именование классов по БЭМ;
- локальные шрифты Raleway.

## Структура

- `index.html` — разметка страницы;
- `styles/` — стили;
- `fonts/` — шрифты;
- `images/` — изображения, логотипы и иконки.
